## 详细变更

### A. 日志抽象层

新增 Log 包，含两个类:

- IkuaiLogger: 接口，定义 debug/info/warn/error/error(msg,t)nsoleIkuaiLogger: 默认实现，[IkuaiSDK-LEVEL] 前缀输出到 stdout/stderr

IkuaiRouter 中:
- 新增 logger 字段（默认 ConsoleIkuaiLogger）
- 新增 setLogger(IkuaiLogger) / getLogger() 方法
- 内部 log(msg) 改为调用 logger.debug(msg)

上层 FreeMyKvm 接入方式:
```java
ikuaiRouter.setLogger(new IkuaiLogger() {
    private final Logger log = LoggerFactory.getLogger("IkuaiRouter");
    public void debug(String msg) { log.debug(msg); }
    public void info(String msg)  { log.info(msg); }
    public void warn(String msg)  { log.warn(msg); }
    public void error(String msg) { log.error(msg); }
    public void error(String msg, Throwable t) { log.error(msg, t); }
});
```

### B. 会话自动续期 — 不实施

原因: 上层 IkuaiRouterFactory 已通过 Redis 缓存 sesskey (TTL 2h) + checkSessKeyValid() + 自动 relogin 形成闭环。SDK 内部若自动 relogin，新 sesskey 不会同步到 Redis，导致并发问题。
