## 修改概览

| 子项 | 问题 | 修复方案 |
|------|------|----------|
| 1.1 | OkHttpClient 每次请求新建实例，连接泄漏 | 改为实例变量，构造时初始化一次，生命周期内复用 |
| 1.2 | Response 未正确关闭，连接不归还连接池 | login() 和 executeAction() 改用 try-with-resources |
| 1.3 | response.body() 可能为 null 导致 NPE | 添加 null 判断，为 null 时抛出明确异常 |
| 1.4 | SSL 初始化失败被 printStackTrace 吞没 | 改为 throw RuntimeException 快速失败 |
| 1.5 | HashMap cookieStore 非线程安全 | 改为 ConcurrentHashMap，接口类型改为 Map |

**附加修复**: pom.xml 增加 `project.build.sourceEncoding=UTF-8` 解决 Windows 环境编译编码问题。

## 详细变更

### 1.1 OkHttpClient 实例复用

**RouterAgent.java**

```java
// 新增实例字段
private final OkHttpClient okHttpClient;

// 4个构造函数中均初始化（示例）
public RouterAgent(String address, int port, boolean https, String username, String pwd) {
    ...
    this.cookieStore = new ConcurrentHashMap<>();
    this.okHttpClient = TrustAllCertOkHttpClient.getTrustAllCertOkHttpClient(cookieStore);
}
```

每个 `RouterAgent` 实例持有独立的 `OkHttpClient`。不同 iKuai 节点对应不同 `RouterAgent` 实例，不会混用连接池节点的多次请求复用同一连接池和线程池。

**移除**: `login()` 和 `executeAction()` 中每次调用时创建新 OkHttpClient 的代码。

---

### 1.2 Response 资源正确关闭

**login() 方法 — 改造前**:
```java
Response response = call.execute();
String response_string = response.body().string();
// response 未 close
```

**login() 方法 — 改造后**:
```java
try (Response response = call.execute()) {
    ResponseBody body = response.body();
    if (body == null) {
        throw new IkuaiRouterException("Login response body is null");
    }
    String response_string = body.string();
    ...
    return loginResult;
}
```

**executeAction() 方法 — 改造前**:
```java
Response response = call.execute();
if (!response.isSuccessful()) { throw ... }
String resp = response.body().string();
response.close();
// 如果 body().string() 抛异常，close() 不会执行
```

**executeAction() 方法 — 改造后**:
```java
try (Response response = call.execute()) {
    if (!response.isSuccessful()) {
        throw new IkuaiRouterException("Error occurred when executeAction, HTTP status: " + response.code());
    }
    ResponseBody body = response.body();
    if (body == null) {
        throw new IkuaiRouterException("Response body is null when executeAction");
    }
    String resp = body.string();
    ...
    return resp;
}
```

try-with-resources 确保无论是否抛异常，Response 都会被关闭。

### 1.4 SSL 初始化异常快速失败

**TrustAllCertOkHttpClient.java — 改造前**:
```java
} catch (NoSuchAlgorithmException | KeyManagementException e) {
    e.printStackTrace();  // 吞掉异常，后续 NPE
}
```

**改造后**:
```java
} catch (NoSuchAlgorithmException | KeyManagementException e) {
    throw new RuntimeException("SSL context initialization failed", e);
}
```

异常会通过 RouterAgent 构造函数向上传递到调用方，快速失败。

---

### 1.5 线程安全 CookieStore

**类型变更**:
- `RouterAgent.cookieStore` 字段: `HashMap<String, List<Cookie>>` → `Map<String, List<Cookie>>`
- 实例化: `new HashMap<>()` → `new ConcurrentHashMap<>()`
- 带 cookieStore 参数的构造函数: 改为 `new ConcurrentHashMap<>(cookieStore)` 拷贝传入的 Map

**接口变更**:
- `TrustAllCertOkHttpClient.getTrustAllCertOkHttpClient()` 参数: `HashMap` → `Map`
- `RouterAgent.getCookieStore()` / `setCookieStore()`: 参数和返回类型改为 `Map`
- `IkuaiRouter.getCookieStore()`: 返回类型改为 `Map`

## API 兼容性影响

| 变更 | 影响 | 兼容性 |
|------|------|--------|
| `getCookieStore()` 返回 `Map` 而非 `HashMap` | 上层代码如果声明为 `HashMap` 接收需改为 `Map` | ⚠️ 源码级不兼容（需重编译） |
| `setCookieStore()` 参数 `Map` | 可接受任何 Map 实现，向后兼容 | ✅ 兼容 |
| 异常消息变更 | `"Error orrcued when executeAction"` → `"Error occurred when executeAction, HTTP status: xxx"` | ✅ 消息更明确 |
| SSL 初始化失败抛 RuntimeException | 之前静默失败后 NPE，现在快速失败 | ⚠️ 行为变更（更合理） |
