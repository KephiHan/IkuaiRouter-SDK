### 3.2 IP 查找算法优化

**改造前**:
```java
// 每个 IP 都线性扫描 DHCPHost + DHCPStatic 列表
for (...each IP...) {
    for (DHCPHost dhcpHost : dhcpHostList) { if (equals) ... }
    for (DHCPStatic dhcpStatic : dhcpStaticList) { if (equals) ... }
}
```

**改造后**:
```java
// 预建已用 IP 集合，内层 O(1) 查询
Set<String> usedIps = new HashSet<>();
for (DHCPHost dhcpHost : dhcpHostList) { usedIps.add(dhcpHost.getIp_addr()); }
for (DHCPStatic dhcpStatic : dhcpStaticList) { usedIps.add(dhcpStatic.getIp_addr()); }
for (...each IP...) {
    if (!usedIps.contains(current_ip)) { return current_ip; }
}
```

**性能提升**: /24 子网(254 IP) + 200 条记录: 约 50000 次比较 → 254 次 HashSet.contains()
