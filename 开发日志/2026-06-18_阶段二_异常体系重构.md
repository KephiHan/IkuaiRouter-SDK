## 设计决策

**方案选择**: 仅在 RouterAgent 层做异常分层（方案B）

**原因**: `IkuaiRouter` 中大量使用 Jackson 的 `objectMapper.readTree()` / `readValue()`，这些方法会抛出 `JsonProcessingException`（checked exception）。如果将 IkuaiRouter 的方法签名改为 `throws IkuaiRouterException`，需要对 30+ 处 Jackson 调用添加 try-catch 包裹，代码改动量过大且增加冗余。

**最终设计**:
- `RouterAgent.login()` / `executeAction()` 内部精确抛出细分异常
- 所有 public 方法签名保持 `throws Exception`（向后兼容）
- 上层调用方可通过 `instanceof` 精确判断异常类型

## 异常类层次

```
IkuaiRouterException (基类, 已有)
├── IkuaiRouterAuthException       — Result=10014, 认证失败/会话过期
├── IkuaiRouterNetworkException    — HTTP 通信失败、响应体为空、序列化失败
└── IkuaiRouterApiException        — Result 非成功码且非认证失败, 含 resultCode 字段
```

## 详细变更

### 2.1 新增异常类

**IkuaiRouterAuthException** — 当 iKuai 返回 Result=10014 时抛出：
```java
public class IkuaiRouterAuthException extends IkuaiRouterException { ... }
```

**IkuaiRouterNetworkException** — HTTP 层面问题时抛出：
```java
public class IkuaiRouterNetworkException extends IkuaiRouterException { ... }
```

**IkuaiRouterApiException** — API 返回非成功结果时抛出：
```java
public class IkuaiRouterApiException extends IkuaiRouterException {
    private int resultCode;  // iKuai 返回的 Result 码
    public int getResultCode() { return resultCode; }
}
```

### 2.2 应用异常分层

**RouterAgent.executeAction() 中的异常映射**:

| 场景 | 抛出异常 |
|------|----------|
| HTTP 状态码非 2xx | `IkuaiRouterNetworkException` |
| response body 为 null | `IkuaiRouterNetworkException` |
| 请求序列化失败 | `IkuaiRouterNetworkException` |
| Result == 10014 (认证失败) | `IkuaiRouterAuthException` |
| Result 非 30000 (业务失败) | `IkuaiRouterApiException` (含 resultCode) |
| IO/网络异常 | `IkuaiRouterNetworkException` (包装原始异常) |

**RouterAgent.login() 中的异常映射**:

| 场景 | 抛出异常 |
|------|----------|
| MD5 初始化失败 | `IkuaiRouterNetworkException` |
| 请求序列化失败 | `IkuaiRouterNetworkException` |
| response body 为 null | `IkuaiRouterNetworkException` |
| IO/网络异常 | `IkuaiRouterNetworkException` (包装原始异常) |

### 附加: MD5 风险注释

```java
// WARNING: MD5 is cryptographically weak. Used here because iKuai API protocol requires it.
// This is NOT a security recommendation - it's a compatibility constraint.
```

## 上层调用方使用示例

```java
try {
    ikuaiRouter.getNetMappingList();
} catch (IkuaiRouterAuthException e) {
    // 会话过期，需要重新登录
    ikuaiRouter.login();
} catch (IkuaiRouterNetworkException e) {
    // 网络问题，可重试
    log.warn("网络异常: " + e.getMessage());
} catch (IkuaiRouterApiException e) {
    // 业务逻辑错误，含 resultCode
    log.error("API错误 [" + e.getResultCode() + "]: " + e.getMessage());
} catch (Exception e) {
    // 其他异常（如 Jackson 解析异常）
    log.error("未知异常: " + e.getMessage());
}
```
