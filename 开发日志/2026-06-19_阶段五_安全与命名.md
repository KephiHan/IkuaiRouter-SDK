## 详细变更

### 5.1 密码存储改进

- RouterAgent.pwd 字段: String -> char[]
- 所有构造函数: this.pwd = pwd.toCharArray()
- login() 中: String pwdStr = new String(this.pwd) 临时使用
- getPwd(): return new String(pwd)
- 新增 destroy(): Arrays.fill(this.pwd, '\0'); this.pwd = null
- IkuaiRouter 暴露 destroy() 方法供上层调用

### 5.2 MD5 风险注释

已在阶段二完成，login() 中 MD5 代码处有 WARNING 注释。

### 5.3 命名修正

完成项:
- Online_user.java -> OnlineUser.java (类名修正)
- SystemStatus 中字段: Online_user onlroperty("online_user") OnlineUser onlineUser
- getter/setter: getOnline_user/setOnline_user -> getOnlineUser/setOnlineUser

跳过项:
- inter_face 字段重命名: 涉及所有 Entity 类的 getter/setter + 上层业务调用方，改动范围过大。现有 @JsonProperty("interface") 已保证 JSON 序列化/反序列化正确，功能不受影响。

### 5.4 并发保护

- 新增 private final Object portLock = new Object()
- findAvailableNetMappingWanPort: synchronized(portLock) 包裹
- findAvailableNetMappingWanPortMultiInterface: synchronized(portLock) 包裹
- addNetMapping: synchronized(portLock) 包裹
- 新增 findAndAddNetMapping(inter_face, portbegin, portend, template): 原子组合方法，查找+添加在同一 synchronized 块内完成

注意: 此同步仅保证单 JVM 实例内的原子性，多 JVM 场景需上层分布式锁。
